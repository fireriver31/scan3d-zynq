# 近似长方体体积与配套上板实验

## 样品及参考测量

样品为近似长方体纸盒。用直尺测得长12.2cm、宽9.2cm、高5.4cm，按长×宽×高计算参考体积606.096cm³，取整为606cm³。尺寸及测量方法记录于2026-11-01，参考值按长方体几何近似计算。

## 单次扫描结果

| 指标 | 结果 |
|---|---:|
| 参考体积 | 606.096cm³ |
| 严格占据体素数 | 349895 |
| 严格体素边长 | 1.2212607981mm |
| 主测量体积 | 637.3279817cm³ |
| 有符号偏差 | +31.2319817cm³ |
| 相对偏差绝对值 | 5.152976% |
| 显示外壳体积 | 642.0825091cm³ |
| 显示外壳相对偏差 | 5.937427% |

主测量采用result.json的volume_cm3，以occupancy.npy的349895个占据体素复算N·d³/1000。显示外壳用于模型查看，另列数值。若采用取整后的606cm³作参考，主测量偏差为5.169634%。本次未设置合格判据，以实际体积偏差量化对照结果。

本次扫描的轮廓回投覆盖率中位数为93.5521%，最低为83.6342%。体积偏差和轮廓诊断均保存在原始结果中。

## 运行组合与功能记录

本次使用38份软件、Notebook和Noto字模，以及scan3d.bit/hwh配对产物。40份文件在安装前后和归档中SHA一致，字模已在本次板上使用。bit的SHA为c563373a98e544cdde2797d4b88f1d3bc1af3f94a703aea0eb769833ea14c606；hwh的SHA为bbfe9e71e3652a2466d3a757e2ed62f8c82dfc47bf64ada1fc089401474f9412。

步骤1至8均有completed事件。初始化和导出FCLK0均为50MHz，同一boot_id，设备树专用no-map的1MiB区域覆盖相机缓存。GT911在线、errors=0，进入结果模式；清晰彩色、屏幕对齐、中文、按钮、旋转、缩放和体积显示七项由现场人工确认。七项人工记录与自动状态字段的生成方式见[字段说明](../data/board_acceptance/cuboid_606/field_meanings.md)。

第7步流程耗时467.179s，第8步491.087s；与历史摆件的输入不同，分别登记单次耗时。第8步完成后，流程末尾为interrupted，flow_exit记录KeyboardInterrupt。模型与结果文件已生成，结束状态和输出保存在归档Notebook中。
